MARLEY — Setup Instructions
============================

Marley is a personal AI assistant (Jarvis-style) with voice, web search,
system management tools, and Canvas LMS homework integration.


1. REQUIREMENTS
---------------
- Python 3.11+
- An Anthropic API key (https://console.anthropic.com)
- Optional: ElevenLabs API key for voice output
- Optional: Playwright + Chromium for Canvas LMS integration


2. INSTALL
----------
Clone the repo and set up the virtual environment:

    git clone <repo-url>
    cd marley
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

For Canvas homework features, also install Playwright:

    pip install playwright
    playwright install chromium


3. CONFIGURE
------------
Create a .env file in the marley/ directory:

    ANTHROPIC_API_KEY=sk-ant-...
    PORT=7777

Optional (for voice output):

    ELEVENLABS_API_KEY=sk_...
    ELEVENLABS_VOICE_ID=JBFqnCBsd6RMkjVDRZzb

Canvas credentials are NOT stored in .env — they're configured through
the chat interface on first use (see step 5).


4. RUN
------
    source venv/bin/activate
    python server.py

Open http://localhost:7777 in your browser.


5. CANVAS LMS SETUP (first time only)
--------------------------------------
Canvas setup happens through the chat — no manual config needed.

1. Ask Marley about homework:
     "What homework do I have this week?"

2. Marley will detect Canvas isn't configured and ask for:
     - Your school's Canvas URL (e.g. howard.instructure.com)
     - Your school email
     - Your school password

3. Marley saves these locally to .canvas_config.json (gitignored,
   never leaves your machine).

4. Marley triggers a headless SSO login. If your school uses 2FA
   (Microsoft Authenticator, etc.), approve the push on your phone.

5. Session cookies are cached for 4 hours. When they expire, Marley
   auto-triggers a re-login — just approve the push again.

Supported: Any Canvas LMS instance that uses Microsoft SSO.
The integration handles Microsoft 2FA (push notifications and code entry).


6. WHAT YOU CAN ASK
-------------------
Homework / School:
  - "What assignments do I have?"
  - "What's due this week?"
  - "Tell me about the research paper assignment"
  - "What are my grades?"
  - "Log into Canvas"

System (if you have the other agents set up):
  - "How's the trader doing?"
  - "What agents are running?"
  - "Start the trading bot"
  - "Check dispatches"
  - "Check YouTube uploads"

General:
  - "What's the weather in DC?"
  - "Search for ..." (web search)
  - Any conversational question


7. FILES
--------
server.py                 Main FastAPI backend + Claude tools
canvas.py                 Canvas LMS integration (auth + API)
static/index.html         Frontend UI
requirements.txt          Python dependencies
.env                      API keys (create this yourself, gitignored)
.canvas_config.json       Canvas credentials (auto-created, gitignored)
.canvas_cookies.json      Cached session cookies (auto-created, gitignored)
.gitignore                Excludes secrets and local state


8. NOTES
--------
- Marley uses Claude Haiku 4.5 for fast responses
- Voice input works in Chrome/Edge (Web Speech API)
- Voice output requires an ElevenLabs API key
- All credentials stay local — nothing is sent to any server except
  the Anthropic API (for Claude) and your school's Canvas instance
- Sessions end when you say "we're good Marley" or "end session"
- Conversations are auto-saved to ~/claude_brain/ if that repo exists
